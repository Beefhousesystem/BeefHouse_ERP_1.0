# 牛室炙烤牛排 · 多分店进销存 ERP 系统

> Beef House · Multi-Outlet Inventory & Operations ERP

餐饮门店的一体化管理系统:库存、采购、中央厨房、财务、人事薪资、报表一站搞定。整套系统是**单一 HTML 文件**,不需要安装、不需要编译,用浏览器打开即可使用。

---

## ✨ 主要功能

| 模块 | 说明 |
|---|---|
| 📊 利润大盘 | 营业额、毛利、净利、SST 代收、损益表、分店对比、经营提醒 |
| 🛒 销售 (POS) | 门店点单收银记录 |
| 🚚 采购进销 | 供应商采购、进货、调拨记录 |
| 🏭 中央厨房 | 中央厨房生产、成品入库、配送调拨 |
| 📦 库存 | 各门店库存清单与出入库 |
| 🍳 配方成本 | 菜品配方(BOM)与成本核算 |
| 📋 盘点 / 损耗 | 定期盘点、报废损耗登记 |
| 💳 应付账款 | 供应商欠款管理 |
| 💰 运营开销 (OpEx) | 水电、租金等运营费用 |
| 🗓️ 月度核算 | 每月成本汇总 |
| 👥 人事薪资 | 员工档案、打卡考勤、排班、请假、薪资单(EPF/SOCSO/EIS/人头税) |
| 📈 报表 | 各类经营报表导出(CSV) |
| ⚙️ 设置 & 审计 | 角色权限、系统设置、操作审计 |

## 🏪 门店结构

- **中央厨房**(Central Kitchen)
- **Setapak店**(Setapak Branch)

> 如需增减门店,修改 `index.html` 中的 `OUTLETS` 列表即可。

## 🔐 角色权限

系统内置多种角色,按权限分级查看/操作(示例):

- **老板 / 人事经理(Owner/HR)** —— 全权,含财务与个人薪资明细
- **区域副经理** —— 全分店,但薪资只看总额
- **店长** —— 本店采购/盘点/损耗/报表
- **厨师长** —— 生产工单/成品入库/配送
- **员工** —— 仅个人自助(打卡、请假、查看本人薪资单)

## 🚀 使用方式

### 方式一:直接打开(演示模式)
双击 `index.html`,用浏览器打开即可。未连接云端时为**演示模式**,可选择角色登录体验,数据保存在本机浏览器。

### 方式二:上线为网站(GitHub Pages)
1. 进入仓库 **Settings → Pages**
2. **Source** 选 `main` 分支、`/ (root)` 目录,保存
3. 稍等片刻,即可通过网址访问:
   `https://yxchong3.github.io/BeefHouse_ERP_1.0/`

---

## ☁️ 云端同步(选用)

系统支持接入 [Supabase](https://supabase.com) 实现**跨分店 / 跨设备实时同步**与**真实邮箱登录 + 白名单**。

1. 在 Supabase 建立一个项目
2. 到项目的 **SQL Editor**,导入本仓库的 `supabase-schema.sql` 建表
3. 在 `index.html` 顶部填入你的 **Supabase 项目网址** 与 **anon key**
4. 保存后重新打开,即启用云端同步与真实登录

> 不填云端资料时,系统以本机演示模式运行,功能照常可用。
